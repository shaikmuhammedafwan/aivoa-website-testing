# AIVOA Website — Manual Software Testing

## Project Overview

This project documents manual software testing and quality analysis performed on the AIVOA website.

The testing focused on website navigation, form functionality, input validation, UI/UX behavior, responsiveness, and identifying usability issues across different screen sizes.

## Testing Areas

- Functional Testing
- Navigation Testing
- Form Validation Testing
- UI/UX Testing
- Responsive Design Testing
- Input Validation
- Usability Testing
- Bug Identification and Reporting

## Test Documentation

The manual testing documentation contains test cases covering:

- Website navigation
- Demo booking functionality
- Mandatory field validation
- Email validation
- Phone number input
- Name and company field handling
- Industry selection
- Dropdown functionality
- Form submission
- Popup behavior
- Mobile responsiveness
